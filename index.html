kget to Excel

Turn an Ericsson kget dump into a workbook: one sheet per MO class, one row per MO, and every value traceable to its line in the file.

The file is read in this browser and never uploaded.

Best on a laptop. On a phone, open this page in Chrome or Safari: browsers inside apps such as LinkedIn often can't pick or save files.

    What the workbook holds
    
    
    
      
    Summary
    The MO count checked against the file's own Total line, and a link to every sheet.
    
      
    A sheet per class
    One row per MO and one column per parameter. Struct members show as struct.member; array elements are joined with a vertical bar.
    
      
    Parameters
    Every value on its own row with its line number in the file. Optional.
    
      
    Checks
    Any line the converter could not place, so nothing is dropped without a trace.
